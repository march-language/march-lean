# A2-reject dual-side skip ledger (accept/ AND reject/).
#
# Enumerates every specs/lang/types/{accept,reject}/*.march file that
# march-lean-check (A2, the independent inference + linearity oracle) reports
# `skip` on (exit 2) — a file whose construct is outside the modeled
# Core+linearity fragment, or that references a name/constructor the engine
# does not model (stdlib/cross-module), or whose annotations are out of
# fragment (generics, refinement, session/cap types), or (reject side) whose
# linearity A2 cannot judge statically (a linear/affine value captured by a
# closure).
#
# A2 independently INFERS types (rather than verifying march's) and cross-checks
# them, and re-derives linear/affine use-discipline, so its skip set is far
# smaller than the whole corpus but each checked file is judged rigorously.
# This ledger is an INVARIANT the harness enforces BOTH directions on BOTH
# sides — a newly-skipping file (coverage regression) or a ledger entry that no
# longer skips (stale entry) fails the run.
#
# Reject-side note: at A2-reject, march-lean-check renders its own accept/reject
# verdict on reject/*.march too, so reject files split into judged (match/
# mismatch) and skipped (out of fragment). The reject files march rejects for a
# reason ERASED from the Core AST A2 sees (desugared-away constructs) are NOT
# skips — they wrong-accept — and live in scripts/known-limitations.txt instead.
#
# Regenerate: run the harness, take the observed skip set (both sides).
